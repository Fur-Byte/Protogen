# ESP platform and framework source integrity

The source pins in `toolchain.lock.json` were derived on 2026-11-27 from
PlatformIO registry release archives for espressif32 7.1.3 (474 files) and
framework-espidf 4.60100.0 / ESP-IDF 6.1.0 (29,845 files). The downloaded
archives' SHA-256 values matched freshly retrieved registry metadata over
HTTPS. The installed Debian package files matched the archive contents.
The archive hashes establish provenance for the committed source-tree pins;
the build verifier checks the installed source tree directly.

The installer verifies the sources after package installation, before its
first build step. The normal ESP32 build wrapper verifies the source trees
before invoking PlatformIO and again before accepting build evidence.
Release packaging requires the resulting source identity evidence when the
lock contains these pins. The source identity is the SHA-256 of a sorted
JSON map from relative file names to file-content SHA-256 hashes.

PlatformIO adds `.piopm`, Python creates bytecode caches, and the pinned
builder creates five IDF files: `version.txt` and the default dummy
component's CMake file and three empty sources. The verifier excludes the
metadata and generated bytecode from source hashing; it validates the
five generated IDF files against their expected contents whenever present.
Unexpected source files and symlinks cause verification failure. These
checks do not establish integrity of cached Python bytecode, Python
interpreter/packages, PlatformIO Core, compiler binaries or other tool
packages, or protect against a concurrent attacker modifying the build
environment. Do not claim complete build-chain authentication from these
source pins alone.

Refresh pins only from independently checked release archives, never by
accepting arbitrary local tree changes. Full hardware and production
qualification remain separate.


On 2026-11-28 the reference platform pin was advanced to espressif32
8.0.0 from a verified registry archive. The ESP-IDF 6.1.0 framework
source pin is unchanged. The old 7.1.3 numbers above are historical.
